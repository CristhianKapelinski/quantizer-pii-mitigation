# experiment/results/ — index

Pre-computed result logs that back every table and figure in the paper.
Each directory holds the small reproducibility artifacts: `canaries.jsonl`
(ground truth), `extraction.jsonl` (the experiment output, one row per
canary x version), `metrics.json` (recomputed verbatim-extraction
metrics), `train_steps.jsonl` (fine-tune telemetry), `delta_norm.json`
(weight-delta Frobenius norms), and per-experiment `*.json` result files.
`RESULTS.md`, where present, carries the verdict for that experiment.

`SCHEMA.md` documents the JSONL schemas. `replay.sh` recomputes every
paper number from these files (no GPU); `reproduce.sh` regenerates them
end-to-end (GPU + pinned environment).

**Not committed (`.gitignore`d — regenerated by the pipeline):** model
weights (`*.safetensors`, `*.gguf`, `*.pt`), the AWQ/GPTQ `quantized*/`
dirs, `corpus.jsonl` / `retain.jsonl` / `calib_*.jsonl` (rebuilt
deterministically from the seed by `qquilt.data`), the held-out text
corpora `enron_holdout.txt` / `wikitext2_ood.txt`, intermediate
`extraction.*partial*` / `extraction_part*` dumps, and `*.npz` logit
dumps (regenerated by the mechanism scripts).
